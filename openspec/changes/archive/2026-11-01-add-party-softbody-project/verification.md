## Source evidence and practical limits

Static inspection covered 45,197 base script records and 120 patch overrides (45,197 unique hashes after overlay). No game script was executed. Relevant decompiled evidence is in project `reference/scripts/`; `reference/script-analysis.json` records paths, hashes and the call chain.

Scripts establish World/CharManager update ordering, main capsule/roll shape, independent extra-test sphere, FIXED_BOUNCINESS selection, normal=.1 / roll=.65 / uncontrolled=.3, and roll mass scaling. `rp3d_wrapper` imports the actual native `reactphysics3d` implementation. Native contact mixing and lose-control logic, the extra sphere's full self-response and exact SoftBodySimulator2 integration remain unresolved.

The project uses a documented planar impulse approximation, Jolt contact margins, CPU-deformed imported meshes and a bounded seven-point solver. Character auto-step/floor snap is disabled in this arena: a diagnostic run showed floor snapping producing an apparent -28.902 vertical displacement velocity at landing; removing that snap restored the native-run bounds. Steps are traversed by jumping. Six angle constraints and native staged jumping are not implemented. This is a runnable structural reconstruction, not a claim of numerical parity with the original game.

Logs: engine `build/party-world-verification.log`, `build/party-source-ownership.log`, `build/party-shadow-test.log`; project `build/world-final.stdout.log`, `build/world-authored.stdout.log`, `build/world-missing.stdout.log`. Test fixtures remain under project `build/world-checks/`.
